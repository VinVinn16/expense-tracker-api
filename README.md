# Expense Tracker API

A RESTful Expense Tracker API built with Spring Boot following clean architecture principles.

## Features

- User Authentication (JWT)
- Expense Management
- Category Management
- Monthly Summary
- Validation
- Swagger Documentation

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Maven
- Docker (Planned)

## Project Status

🚧 Currently under development.
