# Expense Tracker API

A RESTful Expense Tracker API built with Spring Boot following clean architecture principles.

## Features

- Create, Read, Update, and Delete expenses (CRUD)
- PostgreSQL integration
- API Health Check
---------- ONGOING ----------
- Input validation & Error handling
- JWT auth
- Monthly Expense Summaries
- Swagger / OpenAI Documentation
- Docker Support

## Tech Stack

- Java 21
- Spring Boot & Spring Security
- Spring Data JPA / Hibernate
- PostgreSQL
- Maven
- Postman

## Project Status

🚧 Currently under development. Core expense CRUD operations and database integration are implemented
